   135→/** تاریخچه بیرون از استور نگه داشته می‌شود (عکس‌فوری‌ها عمق‌نمایی نمی‌خواهند) */

   139→function ensureHistory(initial: PelcDocument): EditorHistory {
   140→  if (!history) history = new EditorHistory(initial, DEFAULT_CAPACITY)
   141→  return history
   142→}
   143→
   144→/** اعمال سند تازه از تاریخچه + حفظ انتخاب‌های معتبر */
   145→function syncFromHistory(
   146→  set: (partial: Partial<EditorState>) => void,
   147→  get: () => EditorState,
   148→  doc: PelcDocument,
   149→) {
   150→  const h = history!
   151→  const sel = get().selectedLayerId
   152→  const layer = doc.layers.some((l) => l.id === sel) ? sel : (doc.layers[0]?.id ?? null)
   153→  // حفظ انتخاب چندگانهٔ معتبر — شناسه‌های حذف‌شده کنار می‌روند
   154→  const multi = get().selectedLayerIds.filter((id) => doc.layers.some((l) => l.id === id))
   155→  const keepStart = get().selectedClusterStart
   156→  let nextStart = keepStart
   157→  if (keepStart !== null) {
   158→    const l = doc.layers.find((x) => x.id === layer)
   159→    const text = l?.text?.text ?? ""
   160→    if (!l?.text || !letterClusters(text).some((c) => c.start === keepStart)) nextStart = null
   161→  }
   162→  set({
   163→    doc,
   164→    historyVersion: h.version,
   165→    stepCount: h.stepCount,
   166→    position: h.position,
   167→    canUndo: h.canUndo,
   168→    canRedo: h.canRedo,
   169→    labels: h.labels(),
   170→    selectedLayerId: layer,
   171→    selectedLayerIds: multi,
   172→    selectedClusterStart: nextStart,
   173→  })
   174→}

   204→export const useEditorStore = create<EditorState>((set, get) => {
   205→  /** اعمال جهش متن با بازنگاشت perLetter و پیگیری انتخاب حرف */
   206→  const commitTextMutation = (mutation: TextMutation, label: string, extraPerLetter?: Record<string, LetterOverride>) => {
   207→    const state = get()
   208→    const layer = findLayer(state.doc, state.selectedLayerId)
   209→    if (!layer?.text) return
   210→    const base = extraPerLetter ?? layer.text.perLetter
   211→    const perLetter = remapPerLetter(base, mutation)
   212→    const next = withLayer(state.doc, layer.id, (l) => ({
   213→      ...l,
   214→      text: { ...l.text!, text: mutation.newText, perLetter },
   215→    }))
   216→    const keepStart = state.selectedClusterStart
   217→    state.commit(next, label)
   218→    if (keepStart !== null) {
   219→      const mapped = keepStart >= mutation.shiftFrom ? keepStart + mutation.delta : keepStart
   220→      const clusters = letterClusters(mutation.newText)
   221→      if (clusters.some((c) => c.start === mapped)) {
   222→        set({ selectedClusterStart: mapped })
   223→      }
   224→    }
   225→  }
   226→
   227→  const initialDoc = newDocument()
   228→  history = new EditorHistory(initialDoc, DEFAULT_CAPACITY)
   229→
   230→  return {
   231→    doc: initialDoc,
   232→    historyVersion: 0,
   233→    stepCount: 0,
   234→    position: 0,
   235→    canUndo: false,
   236→    canRedo: false,
   237→    labels: [],
   238→    selectedLayerId: initialDoc.layers[0]?.id ?? null,
   239→    selectedLayerIds: [],
   240→    selectedClusterStart: null,
   241→    activeTab: "word",
   242→    stressResult: null,
   243→    viewScale: 0.12,
   244→    favoriteFontIds: [],
   245→
   246→    selectLayer: (id) => set({ selectedLayerId: id, selectedClusterStart: null, selectedLayerIds: [] }),
   247→    selectAllLayers: () =>
   248→      set({
   249→        // لایه‌های قفل‌شده را نمی‌شود کشید؛ در انتخاب‌همه نمی‌آیند
   250→        selectedLayerIds: get().doc.layers.filter((l) => !l.locked).map((l) => l.id),
   251→        selectedClusterStart: null,
   252→      }),
   253→    clearMultiSelect: () => set({ selectedLayerIds: [] }),
   254→    selectLetter: (clusterStart) => set({ selectedClusterStart: clusterStart }),
   255→    setActiveTab: (tab) => set({ activeTab: tab }),
   256→    setViewScale: (scale) => set({ viewScale: scale }),
   257→    toggleFavoriteFont: (id) => {
   258→      if (!PELC_FONT_IDS.has(id)) return
   259→      const cur = get().favoriteFontIds
   260→      const next = cur.includes(id) ? cur.filter((x) => x !== id) : [...cur, id]
   261→      if (typeof window !== "undefined") {
   262→        try {
   263→          window.localStorage.setItem(FAVORITES_KEY, JSON.stringify(next))
   264→        } catch {
   265→          /* حافظه در دسترس نیست (مثلاً حالت خصوصی) — فقط در حافظهٔ نشست */
   266→        }
   267→      }
   268→      set({ favoriteFontIds: next })
   269→    },
   270→    hydrateFavoriteFonts: () => {
   271→      if (typeof window === "undefined") return
   272→      try {
   273→        const raw = window.localStorage.getItem(FAVORITES_KEY)
   274→        if (!raw) return
   275→        const parsed: unknown = JSON.parse(raw)
   276→        if (!Array.isArray(parsed)) return
   277→        // فقط شناسه‌های معتبر مخزن قلم پذیرفته می‌شوند
   278→        set({
   279→          favoriteFontIds: parsed.filter(
   280→            (x): x is string => typeof x === "string" && PELC_FONT_IDS.has(x),
   281→          ),
   282→        })
   283→      } catch {
   284→        /* دادهٔ خراب — نادیده گرفته می‌شود */
   285→      }
   286→    },
   287→
   288→    undo: () => {
   289→      const h = ensureHistory(get().doc)
   290→      const doc = h.undo()
   291→      if (doc) syncFromHistory(set, get, doc)
   292→    },
   293→    redo: () => {
   294→      const h = ensureHistory(get().doc)
   295→      const doc = h.redo()
   296→      if (doc) syncFromHistory(set, get, doc)
   297→    },
   298→    jumpTo: (index) => {
   299→      const h = ensureHistory(get().doc)
   300→      const doc = h.jumpTo(index)
   301→      syncFromHistory(set, get, doc)
   302→    },
   303→    runStressTest: () => {
   304→      // معیار پذیرش پروژه: ۵۰۰ عمل متوالی بدون خطا + واگرد تا سند آغازین
   305→      const h = ensureHistory(get().doc)
   306→      let doc = get().doc
   307→      const layerId = doc.layers[0]?.id
   308→      if (!layerId) {
   309→        set({ stressResult: "سند بدون لایه است" })
   310→        return
   311→      }
   312→      try {
   313→        const t0 = performance.now()
   314→        for (let i = 0; i < 500; i++) {
   315→          const kashida = "\u0640".repeat((i % 3) + 1)
   316→          const next = withLayer(doc, layerId, (cur) => ({
   317→            ...cur,
   318→            text: { ...cur.text!, text: `آزمونِ تاریخچه ${i + 1}${kashida}` },
   319→          }))
   320→          doc = h.apply(next, `گام آزمون ${i + 1}`)
   321→        }
   322→        const elapsed = Math.round(performance.now() - t0)
   323→        syncFromHistory(set, get, doc)
   324→        // بررسی واگرد کامل
   325→        let ok = true
   326→        for (let i = 0; i < 500; i++) {
   327→          const d = h.undo()
   328→          if (d === null) { ok = false; break }
   329→        }
   330→        const backToBase = h.position === 0
   331→        set({
   332→          stressResult: `موفق: ۵۰۰ گام در ${elapsed} میلی‌ثانیه ثبت شد (ظرفیت ${DEFAULT_CAPACITY}). واگرد کامل تا سند آغازین: ${ok && backToBase ? "بله" : "خیر"}`,
   333→        })
   334→        // بازگشت به آخرین وضعیت
   335→        for (let i = 0; i < 500; i++) {
   336→          if (!h.redo()) break
   337→        }
   338→        syncFromHistory(set, get, h.current)
   339→      } catch (e) {
   340→        set({ stressResult: `خطا: ${e instanceof Error ? e.message : String(e)}` })
   341→      }
   342→    },
   343→
   344→    commit: (next, label, coalesceKey) => {
   345→      const h = ensureHistory(next)
   346→      const doc = h.apply(next, label, coalesceKey ?? null)
   347→      syncFromHistory(set, get, doc)
   348→    },
   349→    beginLiveUpdate: (next) => {
   350→      liveDoc = next
   351→      set({ doc: next })
   352→    },
   353→    commitLiveUpdate: (label) => {
   354→      if (!liveDoc) return
   355→      const h = ensureHistory(liveDoc)
   356→      const doc = h.push(liveDoc, label)
   357→      liveDoc = null
   358→      syncFromHistory(set, get, doc)
   359→    },
   360→
   361→    addLayer: () => {
   362→      const state = get()
   363→      const layer = newLayer(`لایهٔ ${state.doc.layers.length + 1}`)
   364→      const next: PelcDocument = { ...state.doc, layers: [...state.doc.layers, layer] }
   365→      state.commit(next, "افزودن لایه")
   366→      set({ selectedLayerId: layer.id, selectedClusterStart: null, selectedLayerIds: [], activeTab: "word" })
   367→    },
   368→    deleteLayer: (id) => {
   369→      const state = get()
   370→      if (state.doc.layers.length <= 1) return
   371→      const next: PelcDocument = { ...state.doc, layers: state.doc.layers.filter((l) => l.id !== id) }
   372→      state.commit(next, "حذف لایه")
   373→      set({ selectedLayerIds: state.selectedLayerIds.filter((x) => x !== id) })
   374→    },
   375→    duplicateLayer: (id) => {
   376→      const state = get()
   377→      const src = state.doc.layers.find((l) => l.id === id)
   378→      if (!src) return
   379→      const copy: Layer = JSON.parse(JSON.stringify(src))
   380→      copy.id = `${src.id}-copy-${Date.now()}`
   381→      copy.name = `${src.name} (کپی)`
   382→      const idx = state.doc.layers.findIndex((l) => l.id === id)
   383→      const layers = [...state.doc.layers]
   384→      layers.splice(idx + 1, 0, copy)
   385→      state.commit({ ...state.doc, layers }, "تکثیر لایه")
   386→      set({ selectedLayerId: copy.id, selectedClusterStart: null, selectedLayerIds: [] })
   387→    },
   388→
   389→    splitLayerIntoWords: (id, opts) => {
   390→      const state = get()
   391→      const layer = findLayer(state.doc, id)
   392→      if (!layer?.text) return false
   393→      const tokens = tokenizeWords(layer.text.text)
   394→      if (tokens.length < 2) return false
   395→      const boxes = measureWordPositions(layer, state.viewScale)
   396→      if (!boxes) return false
   397→
   398→      const wordLayers: Layer[] = tokens.map((tk, i) => {
   399→        const copy: Layer = JSON.parse(JSON.stringify(layer))
   400→        copy.id = newId()
   401→        copy.name = `کلمه: ${tk.token.slice(0, 16)}`
   402→        copy.text = {
   403→          ...layer.text!,
   404→          text: tk.token,
   405→          perLetter: slicePerLetter(layer.text!.perLetter, tk.rawStart, tk.token.length),
   406→        }
   407→        copy.transform = {
   408→          ...layer.transform,
   409→          tx: Math.round(layer.transform.tx + boxes[i].x),
   410→          ty: Math.round(layer.transform.ty + boxes[i].y),
   411→        }
   412→        return copy
   413→      })
   414→
   415→      const idx = state.doc.layers.findIndex((l) => l.id === id)
   416→      const layers = [...state.doc.layers]
   417→      layers.splice(idx, 1, ...wordLayers)
   418→      state.commit(
   419→        { ...state.doc, layers },
   420→        opts?.auto ? "جدا شدن خودکار کلمه‌های جمله" : "تبدیل جمله به کلماتِ مستقل",
   421→      )
   422→      set({ selectedLayerId: wordLayers[0].id, selectedClusterStart: null, selectedLayerIds: [] })
   423→      return true
   424→    },
   425→
   426→    nudgeSelectedLayer: (dx, dy) => {
   427→      const state = get()
   428→      // انتخاب چندگانه فعال است: همه با هم تکان می‌خورند (یک گام تاریخچه)
   429→      if (state.selectedLayerIds.length > 1) {
   430→        const ids = new Set(state.selectedLayerIds)
   431→        const next: PelcDocument = {
   432→          ...state.doc,
   433→          layers: state.doc.layers.map((l) =>
   434→            ids.has(l.id) && !l.locked
   435→              ? { ...l, transform: { ...l.transform, tx: l.transform.tx + dx, ty: l.transform.ty + dy } }
   436→              : l,
   437→          ),
   438→        }
   439→        state.commit(next, "تکان‌دادن همهٔ لایه‌ها", "nudge:multi")
   440→        return
   441→      }
   442→      const layer = findLayer(state.doc, state.selectedLayerId)
   443→      if (!layer) return
   444→      const next = withLayer(state.doc, layer.id, (l) => ({
   445→        ...l,
   446→        transform: { ...l.transform, tx: l.transform.tx + dx, ty: l.transform.ty + dy },
   447→      }))
   448→      state.commit(next, "تکان‌دادن لایه", `nudge:${layer.id}`)
   449→    },
   450→
   451→    setLayerText: (text) => {
   452→      const state = get()
   453→      const layer = findLayer(state.doc, state.selectedLayerId)
   454→      if (!layer?.text) return
   455→      const perLetter = reconcilePerLetter(text, layer.text.perLetter)
   456→      const next = withLayer(state.doc, layer.id, (l) => ({
   457→        ...l,
   458→        text: { ...l.text!, text, perLetter },
   459→      }))
   460→      state.commit(next, "ویرایش متن", `text:${layer.id}`)
   461→    },
   462→    setLayerFont: (fontId) => {
   463→      const state = get()
   464→      if (!PELC_FONT_IDS.has(fontId)) return
   465→      // انتخاب چندگانه فعال است («انتخاب همه»): یک قلم روی همهٔ لایه‌های
   466→      // انتخاب‌شده اعمال می‌شود؛ لایه‌های قفل‌شده و بی‌متن مستثنا هستند —
   467→      // همان الگوی رنگ گروهی، یک گام تاریخچه با کلید ادغام.
   468→      if (state.selectedLayerIds.length > 1) {
   469→        const ids = new Set(state.selectedLayerIds)
   470→        const next: PelcDocument = {
   471→          ...state.doc,
   472→          layers: state.doc.layers.map((l) =>
   473→            ids.has(l.id) && !l.locked && l.text ? { ...l, text: { ...l.text, fontId } } : l,
   474→          ),
   475→        }
   476→        state.commit(next, "قلم همهٔ لایه‌های انتخاب‌شده", "font:multi")
   477→        return
